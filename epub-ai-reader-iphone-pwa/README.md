# EPUB AI Reader — iPhone PWA

یک EPUB Reader موبایل که متن کتاب را داخل مرورگر باز می‌کند و برای متن انتخاب‌شده معنی، ترجمه، توضیح یا گرامر فارسی می‌دهد.

## امکانات این نسخه

- باز کردن فایل EPUB از Files آیفون
- PWA قابل Add to Home Screen
- حالت تمام‌صفحه و Safe Area مناسب iPhone
- ذخیره خودکار آخرین موقعیت مطالعه برای هر فایل EPUB
- تم روشن/تیره با ذخیره تنظیم
- معنی contextual برای کلمه
- ترجمه فارسی
- توضیح ساده و گرامر
- ذخیره واژه‌ها و جواب AI روی همان دستگاه
- حذف واژه‌های ذخیره‌شده
- فایل EPUB به backend آپلود نمی‌شود

## ساده‌ترین روش استفاده روی آیفون: Deploy روی Render

خود آیفون لازم نیست `npm install` اجرا کند. پروژه را یک‌بار روی یک سرویس Node.js قرار بده و بعد فقط URL را در Safari باز کن.

1. این پروژه را در یک Repository خصوصی GitHub قرار بده.
2. در Render یک Web Service جدید از آن Repository بساز. فایل `render.yaml` تنظیمات پایه را دارد.
3. متغیر محیطی `OPENAI_API_KEY` را در Render وارد کن.
4. Deploy را اجرا کن.
5. URL سرویس را در Safari آیفون باز کن.
6. Share → Add to Home Screen را بزن.

از آن به بعد AI Reader مثل یک اپ از Home Screen باز می‌شود.

## اجرای محلی روی کامپیوتر

```bash
npm install
cp .env.example .env
# OPENAI_API_KEY را در .env وارد کن
npm start
```

سپس `http://localhost:3000` را باز کن.

## تنظیم مدل

مدل با متغیر `OPENAI_MODEL` قابل تغییر است. مقدار نمونه `gpt-5-mini` است.

## حریم خصوصی

EPUB در مرورگر خوانده می‌شود و فایل کامل کتاب به سرور ارسال نمی‌شود. هنگام درخواست AI فقط متن انتخاب‌شده و بخش کوتاهی از متن اطراف آن به endpoint پروژه ارسال می‌شود.

## نکته درباره داده‌های محلی

موقعیت مطالعه، تم و واژه‌های ذخیره‌شده در Local Storage مرورگر ذخیره می‌شوند. پاک کردن Website Data در Safari این اطلاعات را حذف می‌کند.
